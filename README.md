# HireSmart
### ML-Based Resume Screening and Ranking System

## Project Overview
HireSmart is a machine learning-based resume screening system that helps recruiters automate the recruitment process by extracting candidate information, matching resumes with job requirements and ranking candidates based on their matching scores.

## Technologies Used
- Frontend: React.js and CSS
- Backend: Node.js and Express.js
- Machine Learning: Python
- Database: MySQL

## Key Features
- Create and manage job requirements.
- Upload multiple resumes.
- Extract candidate information using Python.
- Match candidate skills with job requirements.
- Calculate weighted matching scores.
- Rank candidates based on their scores.
- Manage candidate application statuses.

## Project Modules
1. Frontend interface
2. Backend API
3. Python-based resume processing and matching
4. MySQL database

## Installation Requirements
- Node.js and npm
- Python 3
- MySQL Server
- Visual Studio Code

## Execution
Refer to the project source code and its configuration for installation, database setup and execution instructions.

## Project Purpose
To reduce manual resume screening effort and help recruiters identify suitable candidates efficiently.
